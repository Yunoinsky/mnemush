Why Mnemush

Your agents stop forgetting what they learned

Agents today restart with amnesia every session. Mnemush gives them a persistent memory that consolidates itself — the way sleep consolidates a day's experiences into durable knowledge.

🔎 Semantic recall

Vector + FTS5 hybrid search. Chinese↔English zero-overlap queries still hit.

🕸️ Graph LTM

Memories interlink on add. PageRank hubs, community detection, spreading activation.

🌙 LLM consolidation

consolidate/dream: LLM updates, links, merges, insights, and actively forgets — with protection rules.

🧠 Concept table

An injected priming index tells your agent what it can recall. Prefrontal cues, hippocampus extraction.

⚖️ Self-governing capacity

100MB cap, eviction chain, neuropilization, cold archive. Memory stays tractable forever.

🧩 Cross-agent

One shared DB behind MCP. Pi, OpenCode, any MCP client — same memory, everywhere.

Architecture

Two layers, like a brain

NEUROPILS — content layer · file tree

Any markdown directory tree is memory. Files are the authoritative source: greppable, cat-able, Git-versioned. mnemush import-tree <dir> syncs it into the index.

▲ import-tree  ·  neuropilize + summary entry ▼
MUSHROOM_BODY — index layer · SQLite

Agent experience: full text + vectors + graph. Summary entries for neuropilized memories. Cross-cluster edges. Consolidation, forgetting, and capacity live here.

Try it

Commands that run the memory

$ mnemush add "use jose not jsonwebtoken" --category decision --importance 0.9 $ mnemush search "jose" # semantic + FTS $ mnemush dream # nightly: consolidate + neuropilize + archive $ mnemush consolidate --dry-run # preview the LLM's plan $ mnemush concepts --limit 40 # priming index for the agent $ mnemush import-tree ~/notes --project wiki # any file tree is memory $ mnemush status # capacity + neuropil entries
